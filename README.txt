ASH: THE NIGHTMARE — GitHub Pages prototype

Upload index.html to the ROOT of the public repository. Then open repository Settings > Pages, select Deploy from a branch, choose branch main and folder /(root), and Save.

Controls: desktop WASD/arrows, mouse look, E/Space interact, Shift run, Escape pause. Mobile: landscape orientation; directional buttons, LOOK, RUN and USE.

Prototype features: Three.js first-person 3D maze, randomized layouts and lights, simple enemy pressure/chase, sanity meter, key/exit objective, numeric puzzle, Normal/Hard/Very Hard, Story/Endless modes, Persian UI.

Important: This is a starter prototype, not the complete 500-stage production game. It does not yet include Chabokan AI, persistent saves, custom high-quality models/animations, sound design, or robust enemy pathfinding. Connect AI through a backend that stores the API key as a secret; NEVER place the Chabokan key in index.html. Three.js and Vazirmatn load from external CDNs, so an internet connection is required.
